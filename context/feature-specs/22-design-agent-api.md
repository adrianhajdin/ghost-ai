# Deprecated AI Design API Spec

This historical feature spec has been retired.

Current product state:

- Architect is the single LLM architecture surface.
- Architect uses the internal AI task runner and the Architect conversation route.
- Canvas changes are previewed and applied only after explicit user approval.
- Chat is collaborator chat, not AI chat.
- Arc Forge is an AI-assisted architecture canvas and prompt composer, not an app builder.
- Arc Forge does not execute generated code, build apps, write repositories, or create pull requests in target apps.
