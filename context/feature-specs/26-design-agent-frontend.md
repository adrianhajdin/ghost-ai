# Deprecated AI Design Frontend Spec

This historical feature spec has been retired.

Current product state:

- The AI workspace exposes `Architect`, `Chat`, and `Specs`.
- Architect is the conversational LLM architecture workspace.
- Chat is collaborator-only project chat.
- Specs is dedicated to spec generation, preview, and download.
- Architect messages are persisted separately from collaborator Chat messages.
- LLM canvas changes are previewed before apply and never auto-applied.
